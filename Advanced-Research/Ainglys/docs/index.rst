Features
--------

* **ML Engine**: PyTorch-based training with ACCA framework
* **REST API**: FastAPI service for model management  
* **Rich CLI**: Terminal UI with progress tracking
* **88+ Research Projects**: Novel ML architectures
* **Comprehensive Testing**: 113 tests with 100% pass rate

Quick Start
-----------

Install AI Hub::

    pip install -e .

Run tests::

    pytest tests/ -v

Start API server::

    ai-hub api start
