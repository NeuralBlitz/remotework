## 🚀 Quick Start Commands

### Installation
```bash
# Clone and install
git clone <repository>
cd ai-hub
pip install -e .
```

### Running the Platform

```bash
# Start API server
ai-hub api start --port 8000

# Or use Docker (production)
docker-compose up -d

# Start with monitoring
docker-compose --profile monitoring up -d

# Development with Jupyter
docker-compose --profile dev up -d
```

### Using the CLI

```bash
# Train a model
ai-hub model train --epochs 100

# Distributed training
ai-hub distributed train --workers 4 --gpu

# AutoML optimization
ai-hub automl optimize --strategy bayesian --iterations 100

# Start model server
ai-hub serve start --port 8080

# Create new research package
ai-hub create package --name "my_research" --type "meta-learning"

# Launch dashboard
ai-hub dashboard
```

### Running Tests

```bash
# Phase 1 tests
pytest tests/test_phase1_comprehensive.py -v

# Phase 2 tests
pytest tests/test_phase2_comprehensive.py -v

pytest tests/ -v --cov=ai_hub --cov-report=html
```

## 🐳 Docker Services

The `docker-compose.yml` includes:

1. **ai-hub-api** - Main API server
2. **model-server** - Model serving endpoint
3. **ray-head** - Ray cluster head node
4. **ray-worker** - Ray worker nodes (scalable)
5. **mlflow** - MLflow tracking server
6. **postgres** - PostgreSQL database
7. **redis** - Redis cache
8. **nginx** - Load balancer
9. **prometheus** - Metrics collection
10. **grafana** - Visualization dashboard
11. **dev** - Development environment with Jupyter

### Deploy Production Stack

```bash
# Start all production services
docker-compose up -d

# Scale Ray workers
docker-compose up -d --scale ray-worker=4

# View logs
docker-compose logs -f ai-hub-api

# Stop all
docker-compose down
```

## 🎯 Key Features Highlight

### 1. Research Integration
```python
from ai_hub.integration import ResearchIntegration

hub = ResearchIntegration()
model = hub.compose_architecture_pipeline(
    input_dim=784,
    output_dim=10,
    task_description="MNIST classification"
)
# Combines ADAG + ANAS + ACML automatically
```

### 2. Model Registry with A/B Testing
```python
from ai_hub.model_registry import get_registry

registry = get_registry()
registry.register_model(model, "classifier", metrics={"acc": 0.95})
registry.setup_ab_test("classifier", "v1.0", "v2.0", traffic_split=0.2)
```

### 3. Async Training with WebSockets
```python
# Start async training
response = await async_train(AsyncTrainRequest(epochs=100))
job_id = response['job_id']

# Connect via WebSocket
websocket = await connect(f"ws://localhost:8000/ws/train/{job_id}")
```

### 4. Advanced Visualization
```python
from ai_hub.advanced_viz import (
    TrainingAnimator, AttentionVisualizer, ModelComparator
)

# Training animations
animator = TrainingAnimator()
animator.create_training_animation(history, "training.gif")

# Attention visualization
attn_viz = AttentionVisualizer()
attn_viz.visualize_attention(attention_weights, tokens)

# Model comparison
comparator = ModelComparator()
comparator.add_model("Model_A", metrics)
comparator.create_radar_chart()
```

### 5. Model Interpretability
```python
from ai_hub.interpretability import InterpretabilityDashboard

dashboard = InterpretabilityDashboard(model)

# Saliency maps
saliency = dashboard.compute_saliency(input_image)

# Feature importance
importance = dashboard.compute_feature_importance(X, y)

# Full interactive dashboard
dashboard.create_interactive_dashboard(
    input_sample, X_train, y_train,
    save_path="interpretability_dashboard.html"
)
```

### 6. Jupyter Training Widgets
```python
from ai_hub.training_widgets import TrainingDashboard

dashboard = TrainingDashboard()
dashboard.display()

# Update during training
for epoch in range(100):
    metrics = trainer.train_epoch()
    dashboard.update_metrics(metrics, epoch, total_epochs=100)
```

### 7. Distributed Training
```python
from ai_hub.distributed import DistributedTrainer

trainer = DistributedTrainer(num_workers=4, use_gpu=True)
results = trainer.train_distributed(model_fn, dataset_fn)
```

### 8. AutoML
```python
from ai_hub.automl import HyperparameterOptimizer

optimizer = HyperparameterOptimizer(strategy="bayesian")
best = optimizer.optimize(model_fn, train_fn)
```
